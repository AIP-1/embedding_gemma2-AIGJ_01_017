# Jetson 실습 - EmbeddingGemma 2 멀티모달 임베딩 (AIGJ_01_017)

Jetson Orin Nano Super 8GB에서 EmbeddingGemma 2를 설치하고 텍스트·사진·동영상·음성 검색을 시험한 뒤, 도메인 미세 조정, 웹캠 물체 검색, 사람 동작 인식, 카메라 2대 접근 감지로 확장한 실습 결과다 (1~10단계, 10-8 제외).

**최종 보고서: [report/최종보고서_1-10단계.md](report/최종보고서_1-10단계.md)**

## 결과 요약

| 단계 | 핵심 결과 |
| --- | --- |
| 1~2 환경·설치 | L4T R39를 JetPack 7 경로로 판단, `torch 2.14.1+cu132` GPU 검증, 모델 로드 `(768,)` |
| 3 텍스트 | 768·256·128차원 모두 정답 1위 |
| 4 사진·영상 | 사람 있음/없음은 정확, 사람 수는 구분 못 함 (FFmpeg 문제를 PyAV로 우회) |
| 5 음성 | 경보음·소음·말 내용은 맞힘, 말소리 여부는 못 가림 |
| 6 성능 | 전체 구성 RAM 4.66 GB, GPU 최대 1.77 GB |
| 7 미세 조정 | accuracy@1 0.850 → 0.933 (4.3분 학습) |
| 8 웹캠 검색 | 임베딩 재라벨·YOLOE로 COCO 밖 물체 오인식 개선 |
| 9 동작 인식 | 다수결로 깜빡임 제거, GRU로 박수·팔짱 인식 |
| 10 접근 감지 | 타겟 근처 삼각측량 1~10 cm, 글로 찾은 타겟 3 cm 오차 |

## 폴더 구성

```
setup/    1~2단계 설치 스크립트 (system_setup.sh: 장비당 1회 sudo, user_setup.sh: 계정당 1회)
lab/      2~9단계 실습 코드, 7단계 학습·평가 데이터, 9단계 손 흔들기 녹화 예시
lab/prox/ 10단계 카메라 보정·접근 감지 코드
report/   최종 보고서와 단계별 결과, 10단계 스크린샷 (얼굴 모자이크)
docs/     파일별 역할 안내, 기초 개념 학습 노트
```

## 실행 환경

L4T R39, Ubuntu 24.04, Python 3.12, CUDA 13.2 (드라이버), torch 2.14.1+cu132, transformers 5.20.1, sentence-transformers 6.2.0, 모델 `google/embeddinggemma-2` (bfloat16).

- 실습 폴더는 Jetson의 `~/eg2-lab`, 가상환경은 `~/eg2`다. 코드와 문서의 `<JETSON_IP>`, `<USER>`는 각자의 Jetson 주소와 계정으로 바꿔 쓴다.
- 학습한 모델(`models/`), 카메라 보정 결과(`*.npz`), 웹캠 크롭은 용량·개인정보 때문에 올리지 않았다.
- 모든 .py와 .sh 파일 맨 위에 수정 기록(날짜, 무엇을, 왜)이 있다.
